# 🏦 Bank Account Simulator in Kotlin

A simple console-based Bank Account Management system built using **Kotlin**, implementing foundational programming concepts and **Object-Oriented Programming (OOP)** principles.

---

## ✨ Features
* **Account Creation**: Initialize an account with account number, PIN code, and initial balance.
* **Deposit Functionality**: Securely add funds with validation for positive amounts.
* **Withdrawal System**: Deduct funds with built-in checks to prevent overdrafts and ensure sufficient balance.
* **Balance Inquiry**: Real-time display of the current account balance.

---

## 🛠️ Technologies Used
* **Language**: Kotlin
* **Environment**: IntelliJ IDEA
* **Concepts**: Classes & Objects, Methods, Encapsulation, Conditional Statements (`if-else`).
